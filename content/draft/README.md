# Draft articles

This directory is for articles that are being written or reviewed and are not yet public.

Planned article format:

- one file per article
- filename = slug
- front matter for metadata
- body for article content
- status is implicit from the directory (`draft`)

Moving an article from `draft` to `published` will be the publishing action once the content loader migration is complete.

Draft files must not be included in the production article catalogue.
